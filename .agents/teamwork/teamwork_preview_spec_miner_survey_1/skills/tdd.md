# Test-Driven Development Skill (Local Dump)

TDD is the red → green loop. Tests verify behavior through public interfaces, not implementation details.
- Seams: public boundary you test at. Agree seams up front.
- Anti-patterns: Implementation-coupled, Tautological, Horizontal slicing.
- Work in vertical slices (one test -> one implementation -> repeat).
- Rules: Red before green. One slice at a time. Refactoring is not part of the loop.
